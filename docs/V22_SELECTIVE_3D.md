# V22 선택적 3D 구조물 고도화 기록

## 목적

V21의 연속 하천, 공식 홍수위험범위 기반 범람면, 승인된 카메라 동선을 보존하면서 영상에서 오래 노출되는 등록 농경지와 오송읍복지회관 주변에만 3D 구조물을 추가한다. 광역 배경 전체를 허위 정밀 모델로 채우지 않고, 확인 가능한 데이터와 시각 프록시를 구분해 시제품의 입체감과 설명 가능성을 함께 확보한다.

## 데이터 구분

- 등록 농경지 중심 1.5 km 구역에는 z19 항공영상에서 색상·윤곽으로 검출한 구조물 후보 79개를 사용했다.
- 이 가운데 비닐하우스형 후보는 40개, 기타 지붕형 후보는 39개다.
- 농경지 후보는 모두 image-derived visual proxy, surveyed=false, cadastral=false로 기록했다. 실제 건축물대장 또는 실측 건물이 아니다.
- 오송읍복지회관 주변에는 OSM에 등록된 실제 건물 윤곽 19개를 사용했다. 다만 OSM 윤곽 역시 국가 건축물대장이 아니며 높이는 시각화용 기본값이다.
- 기존 V21의 DEM, z19 항공영상, 연속 하천, 공식 홍수위험범위, 범람 애니메이션을 그대로 재사용했다.

## Blender 구현

- 기준 파일: blender/osong_visual_v21.blend
- 생성 파일: blender/osong_visual_v22.blend
- 농경지 구조물은 지형 높이에 맞춘 박공지붕 메시로 생성했다.
- 비닐하우스와 일반 지붕을 서로 다른 PBR 재질로 구분하고 일반 지붕은 세 가지 색상 팔레트를 적용했다.
- 오송읍복지회관 주변 OSM 건물의 벽·지붕 재질을 구분했다.
- 대피소 표식은 건물군을 가리지 않도록 접근 장면에서 점차 축소했다.
- V20/V21 카메라 위치 11개와 두 차례 범람 흐름은 변경하지 않았다.
- 주요 정지 프레임 승인 후 1280×720, 16fps, 60초 무음 본편을 한 번만 렌더링했다. 이후 에이전트 합성은 이 파일을 재사용한다.

## 검증 결과

- V22 장면 생성과 6개 주요 프레임 렌더링이 완료됐다.
- 농경지 시각 프록시 79개, 대피소 OSM 건물 19개가 장면에 포함됐다.
- 전체, 최대 범람, 농경지 건조·침수, 대피소 접근·근접 프레임을 직접 검토했다.
- 하천 연속성, 농경지 구조물 정렬, 대피소 건물 가시성, 축소된 대피소 표식을 확인했다.
- 검토 상태는 passed_with_limitations이며 사용자가 최종 본편 렌더링을 승인했다. 재사용 무음 본편과 80초 스테이징 합성 영상이 생성됐다.

## 남은 한계

항공영상은 2D 정사영상이고 지형 원자료는 약 30 m SRTM이다. 농경지 구조물의 높이와 형태는 영상용 프록시이며 실측값이 아니다. 대피소 건물은 OSM 윤곽 기반 단순 메시다. 실제 사물 수준의 디지털트윈으로 발전시키려면 국토부 건물통합정보, 지자체 3D 공간정보 또는 드론 사진측량·LiDAR와 같은 추가 원자료가 필요하다.
